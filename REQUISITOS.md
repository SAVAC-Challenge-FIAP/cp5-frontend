# Checkpoint 05 — Resumo do enunciado (App Melodia)

Resumo de `Check-point-05-front.pdf` (FIAP, Engenharia de Software / Front-end Design, Prof. Lucas Sousa).

## O que é para fazer

Landing page para o app de músicas **Melodia**.

- **Público-alvo:** amantes de música, jovens, pessoas em busca de novas descobertas musicais.
- **Estilo visual:** moderno, clean, cores vibrantes, elementos musicais.
- **Diferenciais a comunicar:** qualidade de som superior, playlists personalizadas, descoberta de novos artistas, interface intuitiva.

## Estrutura obrigatória da página

- [ ] **Hero:** título "Melodia: Sua Música, Sua Forma", descrição curta, CTA "Ouvir Agora", vídeo/imagem de destaque.
- [ ] **Apresentação:** benefícios do app com ícones Font Awesome, estilo consistente via Tailwind.
- [ ] **Funcionalidades:** cards/seções separadas, forma visual e clara.
- [ ] **Depoimentos:** citações + fotos de perfil de usuários satisfeitos.
- [ ] **Formulário de contato:** captura de e-mail para marketing, responsivo (Tailwind).
- [ ] **Rodapé:** contato, redes sociais, política de privacidade.

## Tecnologias exigidas

HTML5 · CSS3 · Tailwind · Font Awesome · Google Fonts · JS (opcional, para animações/interações).

## Etapas do projeto

1. **Planejamento:** paleta de cores, tipografia, imagens/ícones.
2. **Desenvolvimento:** estrutura HTML → estilos Tailwind → ícones/fontes → **menu fixo com transparência via JS** → formulário de contato.
3. **Teste:** responsividade em vários dispositivos, funcionalidades, bugs.

## Dicas do professor

- Design clean e minimalista — evitar excesso de elementos e espaço em branco mal usado.
- Áudios sem copyright, se usar: soundcloud.com/musicas-sem-copyright1, freepd.com.

## Entrega

- Deploy no **GitHub Pages** (link final).
- **README** com descrição da aplicação, tecnologias usadas e integrantes.
- Grupo de até 5 pessoas — entregar link do GitHub Pages + repositório no Teams.
- **Apresentação:** demonstrar a página funcionando e explicar o processo.
- Explicar o código com termos técnicos: estrutura HTML, classes Tailwind, layout responsivo, interações JS, organização de arquivos, decisões de interface.
